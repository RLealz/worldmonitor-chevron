# Plan 02 - Add Supplier Risk Panel

## Goal

Make supplier-risk summaries visible in the SCM variant as public-data demo cards with evidence, confidence, and clear synthetic-archetype framing.

## Must Haves

- SCM variant shows a supplier-risk panel or equivalent dedicated card surface by default.
- Cards are clearly marked demo/synthetic archetypes or public-signal summaries.
- Each visible claim includes source/timestamp/confidence/reason either inline or in an evidence section.
- Empty/degraded copy distinguishes missing public data from proprietary data absence.
- Existing variants keep their current panel defaults unless explicitly touched by registration mechanics.

## Risks

- A new panel can accidentally become static and disconnected from public data. Mitigate by using deterministic archetypes first and then refreshing route/chokepoint scores when data-loader has them.
- CSS can drift from the dashboard's dense operational style. Keep the panel compact and reuse existing risk-badge conventions where possible.
- Static config registration touches shared files; verify full typecheck and SCM config guardrails.
