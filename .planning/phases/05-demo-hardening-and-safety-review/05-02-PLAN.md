# Plan 02 - Document Demo Sources and Production Boundaries

## Goal

Add concise presentation-safe documentation that explains public data sources, demo limitations, freshness/confidence behavior, out-of-scope private data, and future production hardening boundaries.

## Must Haves

- Documentation states the SCM dashboard is a public/open-source-data-only demo.
- Documentation explains synthetic archetypes, public demo corridors, public screening signals, and material mapping confidence.
- Documentation distinguishes market context from operational public SCM signals.
- Documentation explicitly defers private ingestion, enterprise RBAC, audit logging, compliance evidence retention, legal determinations, data residency, and production hardening.
- Docs pass the artifact safety guardrail.
