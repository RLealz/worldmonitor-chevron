# Plan 02 - Wire Route Presets and Material Context into SCM UI

## Goal

Make the Phase 4 route/material context visible in the SCM demo by reusing Route Explorer, Supply Chain, and existing energy SCM panels.

## Must Haves

- SCM users can apply public/demo route presets to Route Explorer without manual country/HS setup.
- Route and material context is visible near existing route, chokepoint, route impact, bypass, and country/product workflows.
- Missing or stale public route data shows degraded-state/freshness copy.
- Low-confidence material mappings show fallback copy instead of false precision.
- Energy market signals remain labeled as market context, not operational SCM evidence.

## Risks

- Route Explorer is already a dense modal. Keep preset controls compact and preserve existing keyboard/state behavior.
- Supply Chain already has many data sections. Add route/material context near existing route/chokepoint/material sections instead of creating another broad tab.
- Component copy can drift from tested utility fallback copy. Prefer rendering model-provided labels and fallback strings.
