# Plan 03 - Guardrails and Verification

## Goal

Close Phase 4 with route/material safety guardrails, focused automated tests, SCM build smoke evidence, and planning state updates.

## Must Haves

- Tests prove public/demo route presets do not imply internal Chevron routes.
- Tests prove material mappings expose confidence and fallback copy.
- SCM config tests prove route, port, maritime, chokepoint, material, and energy surfaces remain registered.
- Verification evidence includes focused tests, typecheck, boundary lint, and SCM build smoke.
- Requirements, roadmap, state, and phase verification docs reflect Phase 4 completion only after execution evidence exists.
