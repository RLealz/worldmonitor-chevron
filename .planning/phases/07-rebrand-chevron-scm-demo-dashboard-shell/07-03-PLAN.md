# Plan 03 - Add Branding Regression And Browser Smoke Guardrails

## Goal

Lock the SCM rebrand with automated guardrails that prove the old WorldMonitor promo/author/GitHub-star surfaces are absent and both required logos render in the browser.

## Must Haves

- Static tests cover the branding helper, logo assets, SCM shell source, metadata wiring, settings/docs references, and non-SCM variant preservation.
- Browser smoke proves SCM page title, header brand, demo logo, Chevron logo, absence of old promo/author/GitHub-star surfaces, and continued settings access.
- Existing SCM no-auth/no-Pro and public-artifact safety tests remain green.
- Typecheck and boundary lint pass.

## Risks

- Browser smoke depends on a running dev server or Playwright webServer config. If that path is unstable, document the blocker and keep static tests green.
- Overly broad forbidden-string tests can fail on legitimate implementation identifiers. Scope assertions to SCM-visible shell/docs surfaces.
- Logo rendering tests should assert presence and dimensions, not pixel-perfect brand design.
